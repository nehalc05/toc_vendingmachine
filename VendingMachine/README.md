
# Smart Vending Machine Simulator

## Overview
A C++ based vending machine simulator developed using Theory of Computation concepts, particularly Finite State Machines and Mealy Machines.

## Features
- Product selection
- Coin insertion
- Payment validation
- Product dispensing
- Automatic change return
- Transaction cancellation
- Inventory management

## Technology Stack
- C++
- Finite State Machine (Mealy Machine)
- Graphviz
- Qt (Phase 2)

## Development Plan
Phase 1: Console-based application
Phase 2: Qt graphical interface
